# Trickerion: Legends of Illusion - DA 확장 완전 룰 정리

> 출처: Trickerion Revised Rulebook 2019 (Mind Clash Games, 28p)
> DA(Dark Alley) 확장 포함 기준. 기본게임 전용 규칙은 생략.
> 작성일: 2026-03-02

---

## 1. 게임 개요

- 2~4인, 7라운드 (DA 포함 시)
- 목표: 가장 많은 명성(Fame) 획득
- 핵심 루프: 트릭 학습 → 컴포넌트 수집 → 트릭 준비 → 극장 셋업 → 공연

## 3. 초기 셋업

### 3.1 일반 셋업
1. **트릭 카드**: 4카테고리 덱 분리, 달고르 거주지에 앞면 배치
2. **시장 재고**: 나무1 + 금속1 + 유리1 + 천1 (Buy 영역)
3. **퍼포먼스 덱**: 리버사이드2 + 그랜드마고리안2 + 마그누스판테온2 (위→아래 순서, 뒷면)
   - 극장에 리버사이드 카드 앞면 배치 (인원수 - 1)장
4. **컴포넌트/샤드/코인** 공급 더미
5. **특수 배치카드**: 4개 장소별 덱 셔플, DA 슬롯에 뒷면 배치
6. **턴 카운터**: I 슬롯에 트릭케리언 스톤 배치
7. **예언**: 랜덤 3개 Pending 슬롯에 배치 (1턴에는 Active 예언 없음)

### 3.2 인원수별 슬롯 제한
- **2인**: 다운타운/시장/DA에서 +1AP 슬롯 2개 사용불가
- **3인**: +1AP 슬롯 1개 사용불가
- **4인**: 전부 사용

### 3.3 플레이어 셋업

각 플레이어는 다음을 받음:

| 항목 | 내용 |
|------|------|
| 마술사 카드 | DA면 사용 (능력 아이콘 있는 면) |
| 포스터 카드 | 광고용 |
| 트릭/심볼 마커 | 4심볼 × (4트릭마커 + 1심볼마커) = 20개 |
| 컴포넌트 | 플레이어 선택, **총 코인가치 2** (예: 기본2개 또는 고급1개) |
| Lv.1 트릭 | 선호 카테고리에서 1장, 심볼마커 배치 |
| 배치카드 | **6장**: 극장2 + 작업장1 + 시장1 + 다운타운1 + 뒷골목1 |
| 캐릭터 디스크 | 마법사1 + 견습생1 (보드에 배치), 나머지는 개인 공급 |
| 전문가 1명 | 플레이어 선택 + 확장보드 + 아래 보너스 |
| 코인 | **10/12/14/16** (이니셔티브 순서 1/2/3/4번째) |
| 샤드 | **1개** |

#### 전문가 선택 보너스
- **매니저**: 추가 컴포넌트 (총 코인가치 2), 매니저 확장보드 슬롯에 배치
- **기술자**: 추가 Lv.1 트릭 1장 (아무 카테고리), 기술자 확장보드 슬롯에 배치
- **어시스턴트**: 추가 견습생 1명, 어시스턴트 확장보드 슬롯에 배치

#### 무료 준비 (중요!)
시작 트릭의 컴포넌트 요건을 시작 컴포넌트로 충족하면, 해당 트릭에 트릭마커를 즉시 배치 (무료 Prepare).

### 3.4 시작 명성 & 이니셔티브
- **시작 명성: 5** (명성을 잃을 수 있으므로)
- 이니셔티브 순서: 랜덤 결정 (이후 매 턴 명성 역순)
- **2인**: 1번/3번 슬롯만 사용

## 4. 게임 페이즈 (매 턴)

### Phase 1: 주사위 굴리기 (Roll Dice)
- 선 플레이어가 **6개** 다운타운 주사위를 굴림
- 결과에 따라 다운타운 슬롯에 배치
- 달고르: 학습 가능 트릭 카테고리 결정
- 여관: 고용 가능 캐릭터 결정
- 은행: 획득 가능 코인 수 결정
- **X 결과**: 해당 주사위로는 이번 턴 액션 불가

### Phase 2: 이니셔티브 순서 결정 (Set Initiative Order)
- 명성 **적은 순서**로 이니셔티브 부여 (명성 적은 사람이 먼저)
- **동점 시**: 기존 순서 뒤집기
- **1턴에는 생략**

### Phase 3: 광고 (Advertise)
- 이니셔티브 순서에 따라, 각 플레이어 턴 1회 선택 가능
- **비용**: 이니셔티브 슬롯 번호만큼 코인 (1~4)
- **보상**: 즉시 **2명성**
- 포스터를 이니셔티브 슬롯 위에 배치 (End Turn에 회수)

### Phase 4: 배치 (Assignment Phase)
- **모든 플레이어 동시에** 배치카드를 캐릭터 아래에 뒷면으로 배치
- 캐릭터별 1장씩 (배치하지 않은 캐릭터는 Idle)
- 완료 후 다음 페이즈로

### Phase 5: 캐릭터 배치 (Place Characters Phase)
- 모든 배치카드 **동시 공개**
- 이니셔티브 순서대로 **한 명씩 번갈아** 캐릭터를 장소 슬롯에 배치
- 배치 즉시 AP를 사용하여 액션 수행
- **Idle 캐릭터**: 배치하지 않음, 임금 없음, 배치카드 뒷면으로 뒤집어 표시

### Phase 6: 공연 (Performance Phase)
- 목→금→토→일 순서 (이니셔티브 순서 아님!)
- 퍼포먼스 슬롯의 마법사만 공연 가능
- 상세 규칙은 섹션 7 참조

### Phase 7: 턴 종료 (End Turn Phase)
- 상세 규칙은 섹션 8 참조

## 5. AP(Action Point) 시스템

### 5.1 기본 AP
| 캐릭터 | 기본 AP |
|--------|---------|
| 마법사 | 3 |
| 전문가 (기술자/매니저/어시스턴트) | 2 |
| 견습생 | 1 |

### 5.2 슬롯 보정
- 각 장소(극장 제외)에는 캐릭터 슬롯이 있고, 슬롯마다 AP 보정값이 인쇄
- 총 AP = 기본 AP + 슬롯 보정

### 5.3 샤드 강화 (Enhance Character)
- **극장을 제외한** 모든 장소에서 가능
- 샤드 1개 지불 → AP +1 (캐릭터당 1회 한정)

### 5.4 AP 사용
- 배치 즉시 전부 사용 (저축 불가)
- 각 액션의 AP 비용은 액션 심볼 아래에 원형으로 표시

## 6. 장소별 액션

### 6.1 다운타운 (Downtown)

#### Learn Trick (3 AP)
- 달고르 거주지에서 트릭 1장 선택
- 빈 트릭 슬롯에 배치 + 미사용 심볼마커 1개 배치
- **카테고리 제한**: 달고르 주사위 결과와 일치해야 함 (? = 아무거나)
- 학습 후 해당 주사위를 X면으로
- **명성 문턱**: 트릭의 Fame Threshold 이상이어야 함. 부족분은 코인으로 대납 가능
- **선호 카테고리**: 주사위 무관하게 항상 학습 가능 (주사위는 여전히 X로)
- 컴포넌트 요건 충족 불필요 (학습만!)
- 트릭 반환: 언제든 가능, 트릭마커 전부 공급으로 회수 (극장 위 것도!)

#### Hire Character (3 AP)
- 여관 주사위 결과에 맞는 캐릭터를 개인 공급에서 여관에 배치
- 해당 주사위 X로
- **End Turn 때** 플레이어 보드로 합류 (전문가면 확장보드도)
- 전문가는 종류별 1명 한정

#### Take Coins (3 AP)
- 은행 주사위 값만큼 코인 획득
- 해당 주사위 X로

#### Reroll Die (1 AP)
- 다운타운 주사위 1개 리롤 (달고르/여관/은행 아무거나)

#### Set Die (2 AP)
- 다운타운 주사위 1개를 원하는 면으로 변경 (X→다른 면도 가능)

---

### 6.2 시장 (Market Row)

#### Buy (1 AP)
- **같은 타입** 최대 3개 구매
- 코인 비용: 기본 1, 고급 2, 상급 3 (개당)
- **재고(Buy 영역)에 있는 것만** 구매 가능
- 컴포넌트는 **공급에서** 가져옴 (재고 자체를 가져가는 것 아님)
- 플레이어 보드에 배치 (같은 타입은 겹침, 타입당 최대 3개)
- 언제든 컴포넌트를 공급으로 반환 가능

#### Bargain (1 AP)
- **Buy와 함께만** 사용
- AP 1당 총 구매가격 1코인 할인
- **총 가격 0까지 할인 불가** (최소 1코인)

#### Order (1 AP)
- 재고에 없는 컴포넌트를 주문 영역에 배치
- 같은 타입이 주문 영역에 이미 있으면 불가
- **다음 턴** Orders Arrive 때 재고로 이동

#### Quick Order (2 AP)
- 아무 컴포넌트를 Quick Order 슬롯에 배치
- 즉시 재고에 포함 (이번 턴 Buy 가능)
- **가격 +1코인** 추가
- End Turn 때 Quick Order 컴포넌트는 공급으로 반환

### 6.3 작업장 (Workshop)

**특징**: 각 플레이어 자기 작업장만 사용, 자기 캐릭터만 배치 가능

#### Prepare (1~3 AP)
- 트릭카드에 인쇄된 AP 비용 (트릭마다 다름)
- 트릭마커를 트릭카드의 마커슬롯 수만큼 배치 (겹치는 네모 수)
- 같은 심볼의 트릭마커 사용 (학습 시 배치한 심볼마커와 동일)
- **심볼당 트릭마커 최대 4개** (전체 게임에서)
- **조건**: 컴포넌트 요건 충족 + 트릭카드 위에 트릭마커 0개
- **컴포넌트는 소모되지 않음!** (같은 컴포넌트로 여러 트릭 준비 가능)
- 한 캐릭터로 여러 번 Prepare 가능 (AP 충분하면)

#### Move Tricks (1 AP) — 기술자 고용 후
- 트릭 1장을 기술자 확장보드 슬롯으로 이동/교환

#### Move Components (1 AP) — 매니저 고용 후
- 컴포넌트 더미 1개를 매니저 멀티컴포넌트 슬롯으로 이동/교환

#### Move Apprentice (1 AP) — 어시스턴트 고용 후
- 견습생 1명을 어시스턴트 확장보드 견습생 슬롯으로 영구 이동 (빈 경우만)

### 6.4 극장 (Theater)

**특별 규칙 3가지:**
1. **요일 제한**: 모든 슬롯이 목/금/토/일로 나뉨. 한 플레이어는 **한 요일에만** 배치 가능. 그 요일에 상대가 이미 있으면 불가.
2. **샤드 강화 불가**: 극장에서는 샤드로 AP+1 구매 불가
3. **퍼포먼스 슬롯**: 하단 슬롯은 **마법사만** 배치 가능

#### Set Up Trick (1 AP)
- 작업장의 트릭카드에서 트릭마커 1개를 퍼포먼스 카드의 빈 슬롯으로 이동
- **배치 규칙**:
  - 트릭마커의 카테고리 모서리가 링크 서클에 위치해야 함
  - 같은 색 + 같은 심볼의 마커 2개가 같은 퍼포먼스에 있을 수 없음
- **트릭 링크**: 배치 후, 같은 카테고리 심볼 2개가 같은 링크 서클에 있으면 링크 생성
  - **링크 보너스 (즉시 지급!)**:
    - Lv.1 트릭: **1명성 또는 1코인** (선택)
    - Lv.2 트릭: **2명성 또는 2코인** (선택)
    - Lv.3 트릭: **3명성 또는 3코인** (선택)
    - 링크 서클에 샤드 심볼: 링크에 관련된 **각 플레이어** 샤드 1개 (자기 트릭끼리면 1개만)
  - 한 번 배치로 여러 링크 생성 가능
  - 보너스는 **배치한 트릭의 레벨**에 따름

#### Reschedule (1 AP)
- 자기 트릭마커 1개를 같은/다른 퍼포먼스 카드의 빈 슬롯으로 이동
- 배치 규칙 적용
- **링크 보너스 없음!**

#### Perform (마법사 전용)
- 마법사를 퍼포먼스 슬롯(하단)에 배치
- 배치 시 즉시 효과 없음 — **AP 3 소실**
- 이후 Performance Phase에서 실행
- 마법사를 백스테이지(상단) 슬롯에 배치하면 Set Up/Reschedule만 가능 (Perform 불가)

---

### 6.5 뒷골목 (Dark Alley)

#### Draw First Card (1 AP)
- 특수 배치카드 덱에서 **2장 뽑고 1장 선택** (나머지 덱 밑으로)
- 캐릭터 배치당 **1회만** 가능

#### Draw Further Cards (2 AP)
- Draw First Card와 동일하지만 **2AP**
- 여러 번의 카드 뽑기 시, 모든 카드를 먼저 뽑고 한꺼번에 선택 가능

#### Fortune Telling (1 AP)
- 각 Pending 예언을 시계방향으로 1슬롯씩 이동

### 특수 배치카드 규칙
- 영구 배치카드처럼 사용 (Assignment Phase에서 캐릭터 아래에 배치)
- **1회용**: End Turn 때 사용한 것은 해당 덱 밑으로 반환
- **특수 보너스**: 카드에 인쇄된 강화 효과 (특정 액션 1회 적용)
- 보너스 대신 **+1 AP**로 교환 가능 (항상)
- Idle 시 뒷면 카드는 End Turn 때 주인에게 반환

## 7. 공연 페이즈 (Performance Phase)

### 7.1 순서
**목→금→토→일** 순서 (이니셔티브 순서 아님!)

### 7.2 공연 실행
- 퍼포먼스 슬롯의 마법사 소유자가 퍼포먼스 카드 1장 선택
- **조건**: 선택한 카드에 자기 트릭마커 최소 1개
- 카드 위의 **모든 트릭** 수행 (자기 것 + 상대 것)

### 7.3 수익 지급 (모든 관련 플레이어)

각 플레이어는 자기 트릭마커에 해당하는 트릭카드의 수익(Fame/Coin/Shard) 획득

#### 요일 보정 (모든 관련 플레이어에게 적용)
| 요일 | 명성 보정 | 코인 보정 |
|------|----------|----------|
| 목요일 | **-1** | **-1** |
| 금요일 | 0 | 0 |
| 토요일 | 0 | 0 |
| 일요일 | **+1** | **+1** |

- 보정은 **트릭별** 적용 (트릭 2개면 각각 -1/-1)
- 극장에 캐릭터가 없는 플레이어는 **퍼포머의 요일 보정** 적용
- 트릭의 명성/코인 수익은 **최소 0** (음수 불가)

### 7.4 퍼포머 보너스 (퍼포머만)

수익 외에 추가로:

| 보너스 | 내용 |
|--------|------|
| 링크 보너스 | 퍼포먼스 내 링크 1개당 **1명성** (고정) |
| 어시스턴트 | 극장에 어시스턴트가 있으면 **+2명성** |
| 매니저 | 극장에 매니저가 있으면 **+3코인** |
| 기술자 | 극장에 기술자가 있으면 **+1샤드** |
| 카드 보너스 | 퍼포먼스 카드 하단에 인쇄된 보너스 (Fame/Coin/Shard) |

### 7.5 마커 회수
- 공연 완료 후 카드 위의 **모든 트릭마커** → 소유자의 미사용 공급으로 반환
- 퍼포먼스 카드 자체는 이 시점에서 버리지 않음

### 7.6 게스트 퍼포머
- 퍼포머가 선택한 카드에 다른 플레이어의 트릭마커가 있는 경우
- 게스트는 **자기 트릭 수익 + 요일 보정만** 받음
- 게스트는 링크 보너스, 전문가 보너스, 카드 보너스 **없음**

## 8. 턴 종료 (End Turn Phase)

8단계 서브페이즈:

### 8.1 임금 지급 (Pay Wages)
- 비Idle 견습생: **1코인/명** (어시스턴트 확장보드 견습생은 면제)
- 비Idle 전문가: **2코인/명**
- 마법사: 무임금
- **지급 불가 시**: 미지급 코인 1당 **2명성 감소** (최소 명성 0)
- 코인이 1이라도 있으면 반드시 지급해야 함

### 8.2 캐릭터 귀환 (Return Characters)
- 모든 캐릭터를 플레이어 보드로 반환
- 이번 턴 고용한 전문가의 확장보드 추가

### 8.3 주문 도착 (Orders Arrive)
- 주문 영역 컴포넌트 → 재고(Buy 영역)으로 이동 (기존 재고 교체, 반환)
- Quick Order 슬롯 컴포넌트 → 공급으로 반환

### 8.4 퍼포먼스 카드 이동
- 모든 퍼포먼스 카드 시계방향 1슬롯 이동
- **3턴부터**: 마지막 카드 버림 (위의 트릭마커는 소유자 공급으로 반환, 트릭카드 위가 아님!)
- 퍼포먼스 덱에서 새 카드 1장 앞면 배치 (왼쪽 빈 슬롯)
- 3턴부터 2/3/4인 → 3/4/5장 카드

### 8.5 포스터 반환
- 광고 포스터를 소유자 손으로 반환

### 8.6 턴 카운터 이동
- 트릭케리언 스톤 1칸 전진

### 8.7 예언 이동 (DA)
- Active 예언 버림
- 왼쪽 Pending → Active 슬롯으로
- 나머지 Pending 시계방향 1칸
- 새 예언 1장 뽑아 오른쪽 슬롯에 배치

### 8.8 특수 배치카드 버림 (DA)
- 사용한 특수 배치카드 → 해당 덱 밑으로
- Idle 캐릭터 아래 뒷면 카드 → 소유자 손으로 반환

## 13. 트릭 마커 생명주기

```
학습 (Learn Trick)
  → 트릭카드에 심볼마커 배치
  → 공급에 4개 트릭마커 준비

준비 (Prepare)
  → 공급에서 트릭카드로 마커 이동 (슬롯 수만큼)
  → 조건: 컴포넌트 충족 + 카드 위 마커 0개

셋업 (Set Up Trick)
  → 트릭카드에서 퍼포먼스 카드로 마커 1개 이동
  → 링크 체크 → 보너스 즉시 지급

공연 (Perform)
  → 퍼포먼스 카드의 모든 마커 → 소유자 공급으로 반환

카드 버림 (End Turn 이동)
  → 버려지는 퍼포먼스 카드의 마커 → 소유자 공급으로 반환 (트릭카드 아님!)
```

**불변식**: 심볼당 총 마커 수 = 공급 + 트릭카드 위 + 퍼포먼스 카드 위 = **항상 4**

## 14. 확인 필요 사항

### 14.1 다운타운 주사위 면 구성
- 룰북에는 "6개 주사위를 굴려 달고르/여관/은행에 배치"라고만 언급
- 주사위별 정확한 면 구성 (달고르 주사위 2개? 여관 2개? 은행 2개?)
- 사용자 정보: "견습생, 전문가, 트릭×2, 돈×2" — 이것이 6개 주사위 각각의 면인지 확인 필요

### 14.2 장소별 슬롯 AP 보정
- 사용자 정보: "극장 제외 모든 장소 4슬롯: +2, +1, +1, +0"
- 룰북에는 구체적 수치 미기재 (보드 이미지 참조 필요)
- 2~3인 시 일부 슬롯 사용불가

### 14.3 퍼포먼스 카드 링크 서클 배치
- 28장 각각 다른 링크 서클 배치
- 보드게임 물리 카드 또는 이미지 참조 필요

### 14.4 예언 토큰 27개 개별 효과
- 마술사 워크북에 기재
- 별도 조사 필요

### 14.5 특수 배치카드 40장 개별 효과
- 10장/장소 × 4장소
- 카드 텍스트 참조 필요
